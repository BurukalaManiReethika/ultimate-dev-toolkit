## ✨ Overview

**DevTools Hub** is an all-in-one developer utility website that combines multiple productivity tools into a single clean and responsive interface.

Whether you're formatting JSON, generating secure passwords, creating QR codes, previewing Markdown, or working with color palettes, DevTools Hub provides quick and efficient solutions directly in your browser.

---

## 🎯 Features

### 📄 JSON Formatter
- Format JSON instantly
- Validate JSON structure
- Error handling for invalid JSON

### 🔐 Password Generator
- Generate strong passwords
- Secure random character generation
- One-click password creation

### 📱 QR Code Generator
- Convert text or URLs into QR codes
- Instant QR generation
- Mobile-friendly output

### 🎨 Color Palette Generator
- Generate random HEX colors
- Visual color preview
- Copy-ready color codes

### 📝 Markdown Previewer
- Real-time markdown rendering
- Live preview updates
- Supports common markdown syntax

### 🔤 Word Counter
- Count words instantly
- Character count tracking
- Live text analysis

### 🌙 Dark Mode
- Light/Dark theme toggle
- Theme persistence using LocalStorage

### 📱 Responsive Design
- Mobile-friendly layout
- Optimized for all screen sizes
